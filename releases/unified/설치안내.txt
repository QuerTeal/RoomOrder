테이블 주문 2.7.0 — 키오스크 기능 포함 통합 APK

2.7.0 '지금은 이용할 수 없어요' 화면 자동 복구
- 토스 페이지가 연결·서버 문제로 '지금은 이용할 수 없어요' 화면에 멈추면 4초 뒤 같은 페이지를 자동으로 다시 불러옵니다.
- 계속되면 같은 방 QR로 다시 접속하며 30초 → 2분 → 이후 5분마다 시도합니다. 왼쪽에 "연결 문제로 화면을 다시 불러옵니다"를 표시합니다.
- 연결이 끊겨 '주문 화면을 열지 못했어요'가 나온 경우도 연결이 돌아오면 자동으로 다시 엽니다.
- 결제 단계, 요청 처리 중, 주문 결과가 불확실한 경우에는 자동으로 다시 열지 않습니다.

2.7.0 자동 업데이트(준비)
- 관리자 설정 → 앱 업데이트에서 현재 버전과 업데이트 상태를 볼 수 있습니다.
- 이 APK에는 업데이트 주소가 설정되어 있지 않아 자동 업데이트를 사용하지 않습니다. 주소가 설정된 다음 버전을 한 번 직접 설치한 뒤부터 새벽 3~5시, 쉬는 중일 때 자동으로 설치합니다.
- 기존 앱 위에 설치하면 PIN·방·키오스크·다크모드·미조작 시간·애니메이션 설정을 유지합니다.

2.6.1 장시간 대기 후 QR 만료 방지
- 자동 정리 후 쉬는 동안 10분마다 같은 방 QR로 조용히 다시 접속합니다.
- 오래 비어 있던 태블릿의 첫 메뉴 터치에서 'QR을 다시 인식해주세요' 화면이 나오지 않습니다.
- 빈 장바구니를 확인한 뒤 아무도 터치하지 않은 메뉴 화면에서만 재접속하며, 카운트다운은 계속 숨깁니다.
- 화면이 꺼져 있었거나 네트워크·팝업 때문에 재접속하지 못했다면, 주문 화면의 첫 터치로 먼저 다시 접속합니다. 1~3초 로딩 뒤 새 메뉴가 열리고, 왼쪽 버튼은 그대로 동작합니다.
- 미조작 시 자동 정리를 '사용 안 함'으로 둔 태블릿에는 적용되지 않습니다. 별도 설정은 없습니다.
- 토스 서버의 실제 접속 유지 시간은 공개되지 않았습니다. 만료 화면이 나오면 기존처럼 4~6초 뒤 같은 방 메뉴로 자동 복귀합니다.
- 기존 앱 위에 설치하면 PIN·방·키오스크·다크모드·미조작 시간·애니메이션 설정을 유지합니다.

2.6.0 애니메이션 설정
- 관리자 설정 → PIN 인증 → 화면 설정 → 애니메이션에서 효과별로 조정하고 저장합니다.
- 금액·수량 숫자 굴림: 켬/끔. 끄면 금액과 수량을 바로 표시합니다.
- 주문완료 화면 효과: 켬/끔. 끄면 파란 원·체크·쿠폰 안내 시작 화면 없이 결과를 바로 표시합니다.
- 담기 버튼 움직임: 끔 / 작게(5px) / 중간(10px) / 원본(20px).
- 기본값은 모두 켬·원본(20px)이며, 저장하면 현재 주문 화면에 바로 적용됩니다.
- 기존 앱 위에 설치하면 PIN·방·키오스크·다크모드·미조작 시간 설정을 유지합니다.

2.5.3 원본 애니메이션 복구
- 하단 담기 버튼의 수량·금액 숫자가 굴러가며 바뀌는 토스 원본 효과를 다시 표시합니다.
- 담기 버튼이 위아래로 천천히 움직이는 원본 효과를 다시 표시합니다.
- 주문완료 화면의 체크 표시, 금액이 올라가는 효과, 카드 등장 효과를 다시 표시합니다.
- 가로 배치·큰 글자·버튼 크기 보정은 그대로이며, 주문완료 금액과 '원'은 카드 안 같은 줄에 표시됩니다.
- 기존 앱 위에 설치하면 PIN·방·키오스크·다크모드·미조작 시간 설정을 유지합니다.

2.5.2 자동 정리 반복 방지·외부 페이지 복귀·안내 간소화
- 자동 정리가 끝나면 다음 터치까지 쉽니다. 아무도 없을 때 QR에 계속 재접속하지 않습니다.
- 쉬는 동안 왼쪽 카운트다운이 사라지며, 화면을 터치하면 다시 시작합니다.
- 메뉴·장바구니·주문내역에서 외부 사이트로 나간 경우에도 미조작 시간이 지나면 같은 방 메뉴로 돌아옵니다.
- 결제 단계에서 다른 사이트로 이어진 경우는 결제 중일 수 있어 자동으로 이동하지 않습니다.
- 응답이 느려도 새로 불러온 장바구니 화면을 기준으로만 삭제·확인합니다.
- 왼쪽 안내 문구를 줄이고 '계속 사용' 버튼을 없앴습니다. 화면 어디든 터치하면 취소됩니다.
- 기존 앱 위에 설치하면 PIN·방·키오스크·다크모드·미조작 시간 설정을 유지합니다.

2.5.1 초 단위 자동 새로고침·장바구니 정리·카운트다운
- 기본값: 화면을 100초 동안 터치하지 않으면 장바구니를 비우고 같은 방 메뉴에 다시 접속합니다.
- 관리자 설정 → PIN 인증 → 미조작 시 자동 정리에서 사용 안 함/60초/80초/100초를 선택하고 저장합니다.
- 기존 분 단위 설정은 100초로 전환하며, 기존 사용 안 함은 유지합니다.
- QR 재접속의 중간 주소에서 자동 정리가 중단되던 현상도 수정했습니다.
- 왼쪽에 남은 시간을 표시합니다. 마지막 60초에는 정리 안내와 '계속 사용' 버튼이 나타납니다.
- 60초 선택 시 처음부터 정리 안내가 표시됩니다. 80초는 20초, 100초는 40초 경과 후 안내로 전환합니다.
- 화면을 터치하면 취소하고 시간을 다시 셉니다. 앱이나 관리자 화면에서 돌아오면 새 주기를 시작합니다.
- 정리 중에는 삭제 → 빈 상태 확인 → 같은 방 재접속 안내를 표시하며 뒤로 가기·메뉴 이동은 잠시 막습니다.
- 주문·결제 중이거나 결과가 불확실한 경우에는 정리를 보류합니다. 삭제 실패 시 자동 재시도하지 않고 장바구니 확인 안내를 표시합니다.
- 아직 주문하지 않은 장바구니만 정리합니다. 접수된 주문·주문내역·PIN·방·키오스크 설정은 유지합니다.
- 같은 장바구니를 여러 사람이 사용하더라도 해당 태블릿의 미조작 시간을 기준으로 정리됩니다.
- 원본 QR 재접속 기능이며 토스 서버 만료 방지를 보장하지는 않습니다. 실물 태블릿·실제 서버 동작은 매장에서 확인해 주세요.
- idle-countdown-preview.png와 idle-warning-preview.png는 실제 주문 없는 로컬 검증 화면입니다.

2.4.2 1280×800 및 주문완료 화면
- 1280×800 가로 화면에 메뉴 카드·상세 화면 간격을 맞췄습니다.
- 주문완료 금액과 주문내역을 좌우로 배치하고, 표시 밀도가 높으면 위아래로 배치합니다.
- 완료 금액과 '원'을 같은 줄로 표시하고 밝음·어두움 테마를 적용했습니다.
- PIN·방·키오스크·다크모드 설정은 기존 앱 위에 설치하면 유지됩니다.
- complete-preview.png는 실제 주문 없는 표시 검증 데이터로 캡처한 화면입니다.

2.4.1 전체 UI 점검
- 좁은 화면에서 가격의 '원'이 다음 줄로 밀리던 부분을 수정했습니다.
- 하단 수량·금액을 숫자 애니메이션 없이 원본 값으로 표시합니다.
- 메뉴 이동·방 변경·기기 설정 등의 확인창 글씨와 버튼을 키웠습니다.
- PIN·방·키오스크·다크모드 설정은 유지됩니다.
- 자세한 검사 범위는 UI점검결과.md를 참고하세요.

2.4.0 다크모드
- 관리자 설정 → PIN 인증 → 다크모드 체크 → 저장으로 켭니다.
- 체크를 끄고 저장하면 밝은 화면으로 돌아갑니다. 기본값은 꺼짐입니다.
- 태블릿별로 저장되며 앱을 다시 실행해도 유지됩니다.
- 메뉴·상세·장바구니·주문 확인창과 앱의 로딩·오류·관리자 화면에 적용합니다.
- 테마만 변경할 때는 현재 페이지를 새로고침하지 않고 색상만 바꿉니다.
- 기존 앱 위에 업데이트하면 PIN·방·키오스크 설정을 유지합니다.

2.3.4 QR 만료 자동 복귀
- 장시간 미조작 후 'QR을 다시 인식해주세요' 화면이 나오면 약 4~6초 후 같은 방 메뉴로 자동 재접속합니다. 메뉴 로딩 시간은 별도입니다.
- 정상 장바구니·결제 화면은 유지합니다. 처리 중인 요청이 있으면 기다립니다.
- 주문·결제 결과가 불확실하면 자동 이동하지 않고 결과 확인 안내를 유지합니다.
- 별도 설정은 필요 없습니다. 기존 앱 위에 업데이트하면 PIN·방·키오스크 설정을 유지합니다.

2.3.3 필요한 경우에만 대기 안내
- 수량 조절·장바구니 메뉴 삭제 중에는 현재 화면을 그대로 보여 줍니다.
- 초기 로딩·페이지 이동·담기·주문 처리 때는 대기 안내를 유지합니다.
- 변경 요청 중에는 중복 터치와 뒤로 가기를 막습니다.
- 수량 변경·삭제 결과가 불확실한 경우에는 장바구니 확인 안내가 표시됩니다.

2.3.2 화면 전환·중복 입력 방지
- 가로 화면이 준비될 때까지 대기 안내를 표시합니다.
- 담기·주문 처리 중에는 반복 터치와 뒤로 가기를 차단합니다.
- 시간 초과나 연결 오류가 나면 '장바구니 확인' 또는 '주문내역 확인'으로 처리 결과부터 확인하세요.
- 기존 2.1·2.2·2.3 통합 앱 위에 업데이트하면 PIN·방·키오스크 설정을 유지합니다.

2.3.1 종료 복구
- 주문 화면이 비정상 종료돼도 앱 안에서 같은 방의 첫 메뉴를 다시 엽니다.
- 5분 내 자동 복구는 최대 3회이며 반복 오류 시 '주문 화면 열기'로 재시도합니다.
- 복구 후 재주문 전에 주문내역을 확인하세요. 주문 요청을 자동 재전송하지 않습니다.
- WebView 엔진 자체의 오류 해결이나 실제 태블릿의 장시간 안정성을 보증하는 업데이트는 아닙니다.

모든 방에 dogdive-order.apk 하나를 설치합니다.
지원 방: 1, 2, 3, 5, 6, 7, 8, 9번방

1. Android 13 태블릿에서 APK를 열어 설치합니다.
2. '테이블 주문' 실행 후 관리자가 숫자 6자리 PIN을 직접 설정합니다.
3. 태블릿이 놓인 방을 선택하고 저장합니다.
4. 왼쪽 방 번호와 토스 페이지의 테이블 번호를 확인합니다.

방 변경, 원본 배치, 글자 크기, 다크모드, 새로고침은 관리자 PIN 인증 후 사용할 수 있습니다.
매장·메뉴·가격은 실제 토스 페이지 데이터를 표시합니다.

키오스크 사용:
1. 관리자 설정 → PIN 인증 → 키오스크 설정 → 자동 실행 설정
2. Android 선택창에서 '테이블 주문'을 기본 홈 앱으로 지정합니다.
3. 재부팅 후 저장한 방이 열리는지 확인합니다. 화면 잠금이 있으면 먼저 해제합니다.
4. 전용 기기(Device Owner) 등록 후에는 '주문 앱 잠금'을 켤 수 있습니다.
5. '기기 설정 열기'는 PIN 인증 뒤 앱 잠금을 해제합니다. 점검 후 잠금을 다시 켜 주세요.

화면 켜짐 유지도 관리자에서 조절할 수 있습니다.
일반 APK 설치만으로는 기기 전체 잠금이 적용되지 않습니다.
전용 기기 등록과 자동 실행 해제 방법은 함께 제공하는 '키오스크설치안내.md'를 참고하세요.
2.1·2.2 통합 앱 위에 설치하면 PIN·방·키오스크 설정을 유지합니다.

2.3.0 이전 수정(세션 종료 복귀):
- 마지막 주문 확인창의 글씨 겹침과 작은 화면의 버튼 배치를 수정했습니다.
- '안녕히 가세요' 등 세션 종료 화면이 유지되면 같은 방의 처음 주문 화면으로 돌아갑니다.
- 주문 완료·결제 진행 중에는 자동으로 이동하지 않습니다.
- 반복 접속 실패 시 자동 재접속을 제한합니다. '메뉴 처음으로' 버튼으로 다시 접속할 수 있습니다.

방별 v1 APK와는 별도 패키지이며 이전 설정은 자동 이전되지 않습니다.
실제 주문 전송과 결제는 매장 담당자 입회하에 실기기에서 검수해 주세요.
